# School Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A mobile-friendly React app that parses GCU syllabus PDFs into scheduled, time-estimated assignments with dashboard, calendar, heatmap, grades, and Supabase sync.

**Architecture:** Pure domain modules (parser, classify, estimate, schedule, dates) with unit tests; a local-first store that mirrors writes to Supabase when connected; React views over derived schedule data. Seed data is generated by a script from syllabus text (PDF or `.txt` line fixtures) so the parser is exercised by real input.

**Tech Stack:** Vite 5, React 18, TypeScript, Vitest, pdfjs-dist, @supabase/supabase-js, date-fns (arithmetic only; tz via Intl). Plain CSS with custom properties. GitHub Pages via Actions.

## Global Constraints

- Time zone default `America/Phoenix`; all stored instants are ISO strings with explicit offset.
- Capacity defaults: `weekdayMinutes = 180`, `weekendMinutes = 300`.
- Zero-point items excluded from seed; importer toggle `includeZeroPoint` default false.
- Vite `base: '/school-dashboard/'`. Repo `school-dashboard` under `richardsgeorger-collab`.
- Min tap target 44px; no horizontal page scroll; light and dark themes.
- Every pure module gets tests before implementation (TDD). Commit after each task.
