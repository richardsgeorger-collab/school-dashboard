## 3. Ideas cut, and why

- **Email previews / weekly email.** No email provider (rule), and push already covers the morning note.
- **Multi-select "done" on lists.** Rare on a planner that shows one thing; d on Now does the common case.
- **Push when an announcement adds work.** The read runs in the browser, so there is no server moment to push
  from; the post-sync line and the Inbox badge cover it.
- **Offline work queue.** The app already works offline from local storage; a sync queue would add risk to the
  ledger for little gain.
- **Batch API for backlogs.** Halves reader costs only once there are enough accounts for backlogs to matter.
- **Safari/Firefox extension.** $99/yr Apple account and a wrapper; not until students ask.

   customer.subscription.updated, customer.subscription.deleted, invoice.payment_failed).
